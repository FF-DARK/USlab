# 🏝️ 國立成功大學生物醫學工程學系：超音波與藥物控制釋放實驗室 (范景翔副教授)
**Ultrasound and Drug Controlled Release Laboratory (Prof. Ching-Hsiang Fan, NCKU BME)**

本專案為實驗室官方互動式網站——**「聲波生醫島 (Acoustic Bio-Island)」**，以 2.5D 等距視角互動島嶼呈現六大醫用治療超音波研究領域、即時聲場物理模擬、97 篇完整學術文獻圖書館與團隊介紹。

## 🔬 六大研究園區
1. **🧠 血腦屏障可逆式開啟 (Blood-Brain Barrier Opening)**
2. **⚡ 穿顱超音波神經刺激與聲遺傳學 (Ultrasonic & Sonogenetic Neuromodulation)**
3. **💊 超音波導引精準藥物遞送 (Targeted Acoustic Drug Delivery)**
4. **🔮 聲學微流體與 3D 幹細胞球聚集 (Acoustofluidic 3D Stem Cell Spheroid Assembly)**
5. **📡 超音波與壓電奈米材料細胞訊息傳導 (Cellular Mechanotransduction & Signaling)**
6. **🌊 聚焦聲學渦旋與局部特殊剪切力流場 (Focused Acoustic Vortex & Localized Shear Flow)**

## 📁 檔案結構
- `index.html`：網站主頁面
- `data.js`：實驗室完整中英文資料庫（研究主題、97 篇發表文獻、PI 履歷、成員、相簿、最新消息）
- `simulations.js`：六大超音波研究主題之 HTML5 Canvas 即時物理與生醫模擬引擎
- `app.js`：互動島嶼地圖控制器與內建視覺化編輯器
- `styles.css`：全站樣式表
- `assets/`：島嶼底圖 (`island-map.jpg`)、實驗室主持人照片 (`pi-fan.jpg`) 與實驗室活動照片 (`photos/`)
